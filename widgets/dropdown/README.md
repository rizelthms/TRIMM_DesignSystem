# Trimm Dropdown Widget

## Purpose
A customizable dropdown/select component for Mendix, styled with the TRIMM Design System. Designed for flexible option selection and easy theming.

## Features
- Styled using design system SCSS tokens
- Supports icons, caret, and custom captions
- Optionally executes Mendix actions on item select
- Responsive and accessible

## Usage
1. Place the Trimm Dropdown widget on your Mendix page.
2. Configure the `dropdownItems` property with your options and actions.
3. Optionally set an icon, caption, and caret display.
4. The widget will inherit the current theme and design tokens.

## Theming
Styling is managed via the design system SCSS. To customize, override the relevant SCSS variables or CSS custom properties in your theme.
